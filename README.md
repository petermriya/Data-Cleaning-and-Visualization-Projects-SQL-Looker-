# Data-Cleaning-and-Visualization-Projects-SQL-Looker-
End to end projects created using SQL and Looker


I cleaned the messy Safari Connect data and then wrote views for visualization using basic queries and CTEs. I created the dashboards using Looker Studio, my favorite visualization tool. There are so many insights I could show in the dashboards but I preferred to start with a general overview. More dashboards will be added over time.
